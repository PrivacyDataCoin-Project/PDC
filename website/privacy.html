PDC Wallet

Privacy policy

This policy covers the PDC Wallet app for iOS and this website. Effective 1 October 2026.

What stays on the device

The wallet file, seed phrase, private keys, and transaction history are stored on the iPhone. PDC Wallet does not upload them to an account of ours. There is no sign-in server and no analytics SDK.

If you turn on Face ID, the wallet password is stored in the iOS Keychain so the system can unlock the wallet. You can turn that off in the app, which removes the Keychain item.

Remote node

The app syncs with a PDC node you choose. The default is a public node. That connection uses the node’s address, so the node sees your IP address, the blocks your wallet requests, and any transaction you broadcast. The view key is not sent to the node for a normal scan. The node operator can keep ordinary connection logs. We do not use that traffic to build an advertising profile.

Camera and photos

The camera is used only when you scan a QR code. The photo library is used only when you pick a backup or QR image, or when you choose to save an image. Those files are not uploaded by the app.

Website

privacydatacoin.com is a static site. It does not set an account cookie and does not run third-party advertising. The host may keep standard server logs (IP address, page, time) for security.

Children

PDC Wallet is not directed at children under 13.

Contact

Questions about this policy: use the contact path published on privacydatacoin.com or the project repository at github.com/PrivacyDataCoin-Project/PDC.
